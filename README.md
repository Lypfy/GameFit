<h1> NOTE </h1>
<h2> 1. Cách chạy dự án </h2>
Mở CMD -> truy cập thư mục GameFit -> gõ "npm run dev"
(Cấu hình câu lệnh chạy trong "script" ở file package.json)
<h2> 2. Khi cài thư viện </h2>
Gõ
  npm install <tên-thư-viện> --save
  Hoặc 
  npm i <tên-thư-viện>
(Để lưu vào dependencies) - dependencies như là một docker
